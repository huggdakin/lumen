# LUMEN — Тоннель света

**LUMEN** — динамичный 3D-раннер в неоновом цилиндрическом тоннеле, разработанный на **React 19 + TypeScript + Three.js (WebGL) + Tailwind CSS v4** с полной поддержкой **Yandex Games SDK v2** и глубокой оптимизацией под мобильные устройства (iOS / Android / планшеты) и ПК.

---

## Концепция и геймплей

Вы управляете последней живой Искрой, летящей сквозь гаснущий тоннель. Главная особенность игры — **Свет одновременно является вашим здоровьем и вашей видимостью**:
- Со временем запас света непрерывно тает (а каждые **15 000 очков** скорость угасания возрастает на **+3%**).
- Чем меньше света остаётся у Искры, тем гуще смыкается тьма вдали тоннеля и тем сложнее заранее заметить угрозы.
- Когда свет падает до `0%`, искра гаснет — забег завершается (с возможностью **однократного возрождения** или **удвоения награды ×2** за просмотр вознаграждаемой рекламы).

### Объекты на трассе
| Объект | Описание и эффект |
| :--- | :--- |
| **Светлячок (Orb)** | Восполняет запас света, увеличивает счёт и наращивает множитель **Комбо** (таймер удержания — `2.4 с`). |
| **Тёмный осколок (Shard)** | Статичная мина. Столкновение отнимает `26%` света (`+1%` каждые `20 000` очков) и сбрасывает комбо. |
| **Мина-охотник (Hunter)** | Самонаводящаяся шипастая мина, смещающаяся по дуге тоннеля навстречу курсу игрока. |
| **Лазерная стенка (Wall)** | Вращающаяся дуга-шлюз, перекрывающая часть сечения тоннеля. Проходить нужно через открытый зев по ритму вращения. |
| **Вспышка (Flash)** | Сжигает все осколки и мины-охотники на `95 м` впереди, восполняет `+17%` света и начисляет бонусные очки за каждую уничтоженную угрозу. |
| **Магнит (Magnet)** | В течение `7+ секунд` притягивает светлячков с соседних дорожек к вашей Искре. |
| **Щит (Shield)** | Защитная сфера на `15 секунд`: полностью поглощает следующее столкновение с любым препятствием. |
| **Перезаряд (Overcharge)** | На `4.7 секунды` обращает убыль света в рост и ускоряет полёт на `+14%`. |

### Риск и мастерство: «Впритирку» и «Поток ×1.5»
- **Впритирку (Near Miss):** пролёт в непосредственной близости от мины, охотника или края лазерной стенки без касания приносит `+25` бонусных очков, немного восстанавливает свет и даёт `1` заряд риска.
- **Поток (Flow ×1.5):** `3` прохода впритирку подряд активируют режим **Потока** на `6 секунд`, увеличивая все получаемые очки в **1.5 раза**.
- **3D-Сонар:** в правом нижнем углу экрана работает живой 60/120 FPS радар в изометрической проекции (60°), отображающий кольца тоннеля, вашу Искру, светлячки, баффы, мины, охотников и дуги вращающихся стенок на `115 м` вперёд, а также подсвечивающий опасность на текущем курсе.

## Управление

Игра автоматически адаптирует интерфейс под десктоп и сенсорные экраны:
- **Мобильные устройства и планшеты (iOS / Android / iPadOS):**
  - **Боковые кнопки поворота** слева и справа экрана (увеличенной ширины и удвоенной высоты для надёжного хвата большими пальцами в портретной и альбомной ориентации).
  - **Свайп / перетаскивание пальцем** в любой точке экрана для плавного манёвра по окружности тоннеля.
- **Клавиатура и мышь (ПК):**
  - `A` / `D` или стрелки `←` / `→` — вращение вокруг оси тоннеля.
  - Перетаскивание мышью с зажатой кнопкой — свободный поворот по дуге.
  - `Пробел` / `P` / `Esc` — пауза и продолжение игры.
  - `R` / `Enter` — быстрый рестарт забега.

## Экономика, кастомизация и прогрессия

В игре действует единая прозрачная валюта — **✦ Искры (Sparks)**:
- За каждую полную `1 000` очков забега начисляется `1 ✦`.
- Дополнительные искры выдаются за выполнение **ежедневных заданий** (3 миссии в день), открытие **14 достижений**, просмотр вознаграждаемой рекламы и внутриигровые покупки.

### Магазин и 3D-осмотр (`Inspector`)
Каждую модель искры и каждый тоннель можно перед покупкой рассмотреть в интерактивном **3D-вьюпорте** (вращение на 360°, приближение, режим полёта внутри тоннеля):
1. **8 скинов Искры (`src/game/sparkSkins.ts`):**
   - *Бесплатные:* «Солнечная искра», «Крио-ядро», «Розовый кварц».
   - *Авторские с игровыми перками:*
     - **Аврора** (`320 ✦`) — двойная орбита со спутниками, свет гаснет на `6%` медленнее.
     - **Горнило** (`650 ✦`) — лавовое ядро с пламенем кометы, магнит держится `10 с`.
     - **Пульсар** (`1 050 ✦`) — нейтронная звезда с джетами, светлячки дают `+12%` света.
     - **Умбра** (`1 500 ✦`) — горизонт событий, первый удар за забег не сбрасывает комбо.
     - **Сверхновая** (`2 200 ✦`) — огранённый кристалл с гироскопом и ударными волнами, старт со щитом и `−4%` убыли света.
2. **8 архитектур тоннелей (`src/game/tunnels.ts`):**
   - *Бесплатные:* «Холодный импульс», «Медные кольца», «Полярная глубина».
   - *Премиальные (с уникальными GLSL-шейдерами неба и 3D-эффектами взаимодействия):* «Лимонный свет» (`900 ✦`), «Нулевая точка» (`1 400 ✦`), «Жерло вулкана» (`1 900 ✦`), «Кристальный разлом» (`2 600 ✦`), «Призматический сон» (`3 400 ✦`).
3. **5 расходных баффов на старт забега (до 2 слотов одновременно):**
   - «Щит на старте», «Расширитель магнита», «Светлячки-дозаправщики», «Пепельный оберег», «Талисман потока».

## Оптимизация для мобильных устройств и устранение рывков

В текущей сборке выполнен комплекс оптимизаций рендера, памяти и ввода для стабильных **60/120 FPS** без микро-фризов:
1. **Увеличенные мобильные кнопки поворота (`MobileSteerPads`):**
   - Боковые кнопки управления главной искрой расширены (`w-14 sm:w-16`) и увеличены по высоте ровно в **2 раза** (`h-48 sm:h-56` с защитой `max-h-[70dvh]` для низких горизонтальных экранов).
   - Устранён баг «залипания» направления при выходе в паузу или сворачивании браузера во время удержания кнопки.
   - Добавлена защита от мультитач-конфликтов (`pointerId` трекинг) между свайпом по экрану и нажатием боковых кнопок.
2. **Предварительный прогрев пула объектов и компиляция шейдеров (`prewarmPoolAndShaders`):**
   - Все виды препятствий (включая лазерные стенки с кастомным GLSL-шейдером `wallArcMat`, мины-охотники, светлячки и все 4 типа баффов) заранее создаются в `entityPool` и компилируются через `renderer.compile(scene, camera)` на этапе загрузки. Появление первой стенки или баффа во время полёта не вызывает компиляции шейдеров и фриза.
3. **Ноль аллокаций (Zero-GC) в горячем цикле 60/120 FPS:**
   - В `Engine.buildRadarDots()` и в `Sonar` (`src/components/ui.tsx`) полностью устранены покадровые аллокации временных массивов, кортежей проекции `[px, py, depthKey]`, градиентов и объектов точек сонара. Это избавляет мобильные движки JavaScript (iOS WebKit JSC / Android V8) от пауз сборщика мусора (GC) во время забега.
4. **Сглаживание времени кадра (`smoothDt`) и независимая от FPS физика отклика:**
   - Джиттер `requestAnimationFrame` на мобильных экранах сглаживается скользящим окном, а поворот искры, сглаживание кнопок (`steerVel`), изгиб метеорного хвоста и FOV камеры переведены на экспоненциальное затухание `1 - Math.exp(-k * dt)`.
5. **Оптимизация мобильного композитора и GPU Fill-Rate:**
   - Из CSS-анимации всплывающих плашек (`@keyframes popup`) убран покадровый `filter: blur()`, вызывавший просадки FPS на телефонах в момент проходов «Впритирку» и «Комбо».
   - Индикаторы света и комбо переведены со свойства `width` (вызывающего пересчёт Layout/Paint) на композитный `transform: scaleX(...)`.
   - Полноэкранное свечение тревоги при низком свете переведено с тяжёлого `inset box-shadow` на аппаратный `radial-gradient` с `opacity`.
   - Фоновый рендер основной 3D-сцены автоматически приостанавливается на паузе, экране финала и при открытии полноэкранного Магазина / 3D-осмотра.

## Структура проекта

```text
├── index.html                 # Точка входа HTML, мета-теги, подключение шрифта Unbounded и /sdk.js

│   ├── main.tsx               # Монтирование React-приложения

│   ├── components/
│   │   ├── Screens.tsx        # Экраны: Загрузка, Меню, HUD, MobileSteerPads, Пауза, Финал, Лидеры, Правила
│   │   ├── Shop.tsx           # Магазин: Валюта, Скины, Тоннели, Баффы, Достижения
│   │   ├── Inspector.tsx      # Интерактивный 3D-осмотр скинов и тоннелей
│   │   └── ui.tsx             # Общие UI-компоненты, 3D-Сонар на Canvas, шкала света, звуки наведения
│   └── game/
│       ├── Engine.ts          # 3D-движок игры на Three.js (сцена, физика, спавн волн, пул объектов)
│       ├── Sound.ts           # Процедурный синтезатор WebAudio (генеративная музыка меню/забега и SFX)
│       ├── sparkSkins.ts      # Генератор 3D-моделей, процедурных текстур и 2D-превью скинов Искры
│       ├── tunnels.ts         # Архитектура тоннелей, процедурные текстуры обшивки и GLSL SkyDome
│       ├── tunnelFx.ts        # Шейдерный слой динамического освещения и бликов на своде тоннеля
│       ├── viewer.ts          # 3D-сцены SkinViewer3D и TunnelViewer3D для витрины Магазина
│       ├── economy.ts         # Конфигурация тоннелей, баффов, достижений и каталога покупок
│       └── state.ts           # Локальное и облачное сохранение, расчёт итогов забега и ежедневных миссий
```

## Установка и сборка

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки (Vite)
npm run dev

# 3. Сборка продакшн-билда (включая бандлинг в dist/)
npm run build

# 4. Локальный предпросмотр собранного билда
npm run preview
```

### Примечание по Yandex Games SDK
В `index.html` подключён `<script src="/sdk.js"></script>`. При запуске на платформе **Яндекс.Игры** скрипт отдаётся окружением площадки автоматически. При локальной разработке отсутствие `/sdk.js` штатно обрабатывается обёрткой `src/yandex.ts`: все вызовы облачных сохранений, рекламы, лидербордов и платежей безопасно работают в локальном демо-режиме.
