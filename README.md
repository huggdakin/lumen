# LUMEN: Тоннель света — 3D-игра для Яндекс.Игр

## Концепция
Ты — последняя искра в мёртвом тоннеле. **Свет = здоровье и зрение одновременно**: шкала угасает
каждую секунду, и чем её меньше — тем плотнее туман, тем позже видны осколки и тем сильнее давление
тьмы (гаснут даже «окна» в космос). Игрок постоянно выбирает: безопасная дистанция или рискованная
связка светлячков.

Управление: `A / D`, `← →`, свайп/мышь. `Пробел`/`Esc`/`P` — пауза, `R`/`Enter` — рестарт.

Сложность: старт 23 м/с (было 20), осколков на ~15% больше, после 60% сложности стены и
змейки становятся плотнее; после **10 000 очков** убыль света растёт чуть медленнее
(+4/с на ступень, потолок 13/с), зато цепочки светлячков в тьме сыпятся на 20% чаще —
высокий скилл всё ещё спасает. Крутящиеся стенки появляются после 350 м и видны на сонаре
три точками по пролёту дуги.

## Игровые механики
| Механика | Эффект |

| ⚡ Вспышка (молния) | сжигает осколки и мины впереди, +25 за каждый |
| 🧲 Магнит | 7–12 с притягивает светлячков |
| 🧱 Стенка | дуга тоннеля вращается: удар −27% света, кромка зева — near-miss |
| 💣 Мина-охотник | шипастая мина с тонкими светящимися кольцами: медленно целится в дугу игрока (−27% света) — нельзя стоять на одной линии |
| 🔋 Перезарядка (батарея) | 5 сек свет растёт (+4/с) и скорость +15% — рискни быстрее |

## Монетизация и удержание
- Interstitial каждые 2 забега; **не показывается** владельцам Яндекс.Плюс и купившим «Убрать рекламу».
- Rewarded-точки: продолжение после смерти · ×2 награда · +70✦ · бесплатный ящик.
- Лидерборд `lumenScore` + панель «Лидеры» с подсветкой своей строки; виджет «Оцените игру» при рекорде.
- Retention: 3 задания дня (ротация по дате), 7-дневный стрик, сезон на 10 уровней с двумя треками,
  8 достижений, ящик с гарантийным счётчиком (pity 7), экипировка баффов перед забегом,
  история забегов и live-обгон рекорда прямо в полёте.

## Визуал и звук
- **Тоннель — спокойно и читаемо.** Обшивка: крупные панели (8×4 на тайл, 6 тайлов по длине) с мягкими
  вертикальными швами и редкими окнами-иллюминаторами в космос — без полос, решёток и мелких деталей.
  Секций-колец 22 (шаг 8), направляющих лучей 6, внешних шпангоутов 8, линий скорости 150 —
  конструкция даёт глубину и ощущение крена, но не шумит.
- **«Пол» без стрелок.** Жёлтые шевроны убраны: вместо них тонкая непрерывная линия света в цвете темы
  (в базовом «Глубоком космосе» — холодная сине-белая) с едва заметными рисками, которые скроллятся
  вместе со скоростью. Ориентация «где низ» остаётся, мигалки — нет.
- **6 покупаемых фонов**: Глубокий космос (free), Неоновый прибой, Янтарный реактор, Ледяной провал,
  Багровая пустота (◆/₽), Протокол «Нова» (◆/₽). Тема задаёт палитру панелей, цвет неба и тумана,
  звёзды, планеты, туманности, кольца, линию пола и перила; текстуры кэшируются по id темы.
- **Главный экран разгружен**: слева — только логотип, одна строка описания, кнопка «Играть» и подсказка
  управления; справа — одно окно профиля (рекорд, кошелёк, сезон, 3 строки заданий, переключатели скина
  и фона). Реклама/магазин/лидеры/звук вынесены в четыре иконки в шапке, правила и настройки — в отдельный
  оверлей «Как играть · звук». Бегущая строка и сетка карточек убраны.
- **Плашки в игре компактные**: 3.4×0.95 в мировых единицах, тёмная подложка + цветная рамка,
  белый текст 52–72px (900), рендер поверх сцены без depth-test. Чипы HUD — 10–12px.
- **Музыка**: тихий пад Am–F–C–G с glide-переходами, дилеем и редкими пиццикато (уровень 0.06)
  + переключатель выкл / тихо / обычно. Тревожный НЧ-пульс — только в темноте.

## Сборка и публикация
```bash
npm install && npm run build   # → dist/index.html, ~246 КБ gzip, один файл
```
1. Архив из содержимого `dist` (index.html в корне) → «Добавить игру» в консоли разработчика.
2. Лидерборд **lumenScore** (число, по убыванию) + товары из списка SKU выше.
3. Иконка 512×512, обложка, скриншоты 1920×1080 — захвати магазин, новый фон и финал с ×2.
4. В черновике проверь: рекламу, покупки, мобильный свайп, автопаузу при сворачивании вкладки.

## Изменения баланса и визуала (последняя правка)

* Сложность ≈ −10%: старт 23.4 м/с, медленнее нарастание, свет гаснет медленнее, удар −26%, паузы между волнами +10%.
* Баффы ≈ −6%: вспышка, магнит, перезаряд, расходники и шанс появления.
* Тоннели: все сектора — простые панели без решёток, порталов и колец планет; платные отличаются только палитрой.
* Дрейфун — оранжевый. В красных/оранжевых тоннелях («Багровая пустота», «Янтарный реактор») препятствия холодно-белые с тёмной подложкой, поэтому не сливаются со стенами.
* Искра и все её скины — на 15% меньше.


## Последняя правка

* Магазин: плашка 3D на превью, одинаковая сетка «Скины»/«Тоннели», покупки по возрастанию и подсветка выгодных пачек, понятные иконки вкладок.
* Тоннель «Солнечная корона» заменён на «Жерло вулкана» (красно-оранжевая лава); «Нулевая точка» и «Призматический сон» поменялись местами по цене.
* Препятствия на 15% меньше с тонкой светящейся кромкой; баффы на 22% больше; новые модели «Вспышки» (молния) и «Перезарядки» (батарея); «Дрейфун» заменён миной-охотником.
* Плашки в игре: без лишних символов, показываются на ~1 с дольше и стали компактнее. У искры есть шлейф.
* Звук: спокойная глубокая музыка меню, отдельная мелодия забега, мягкий сбор светлячков с басом, звук наведения на любые кнопки.
